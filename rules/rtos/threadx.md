# ThreadX Adapter Rules

Status: draft

## Scope

ThreadX-specific interfaces and configuration, including thread lifecycle, ISR-callable
interfaces, synchronization objects, queues, memory pools, and scheduler behavior.
Runtime-independent requirements belong in [RTOS common](common.md).

## Load when

Changing code that calls ThreadX interfaces or depends on ThreadX configuration.

## Rules

No normative rules have been defined yet.
